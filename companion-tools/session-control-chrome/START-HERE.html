A little less tab chaos.

Session Control brings your Claude Code cloud session links, accounts, and next steps into a Chrome tab.

How separate logins work

One dashboard tab. A dedicated Chrome profile window for each account. The small Mac helper opens the right profile so logins stay separate.

Set up the dashboard

  1. Move this unzipped package to a permanent folder.
  2. Open chrome://extensions in Google Chrome.
  3. Turn on Developer mode, click Load unpacked, and select this package’s extension folder.
  4. Pin the extension, then click its toolbar icon. It opens the dashboard in a new tab. ⌘⇧Y also opens it.

Set up separate accounts

  1. Install Node.js 22 or newer on your Mac if needed.
  2. Add an account in the dashboard using Isolated Chrome profile.
  3. Open mac-helper/Install Mac Helper.command from this package. Paste the extension ID shown in Settings → Mac helper. If it does not launch Terminal, type bash and a space in Terminal, drag in that command file, and press Return.
  4. Click Check connection in Settings, then go to Accounts → Open account and sign in to Claude.
  5. Repeat for your other accounts. Copy a session URL from its account window, then use Save session in the dashboard and choose its account.

No npm installation is needed to use the app. There are no runtime npm dependencies.

A few useful details

Saved session labels, notes, repositories, and branches are set by you. Live progress is not monitored. Claude conversations stay in Claude. Names and emails are labels you provide; check the signed-in identity in each account window.

Use Explore a sample workspace to see the layout. Sample data never overwrites your saved workspace. Use Settings → Export backup to save metadata and notes; logins are managed by Chrome and are not in the backup.

For a single account without the helper, choose This Chrome profile. Only one account can use that shared login.
