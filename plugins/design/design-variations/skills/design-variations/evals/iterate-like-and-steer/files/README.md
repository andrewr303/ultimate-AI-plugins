# Ledgerly (test fixture)

A small invoicing web app used to exercise the design-variations skill. Plain HTML/CSS/JS, no build step.
Open `src/invoices.html` in a browser. Design tokens live in `src/tokens.css`.

Screen under test: **Invoices list** — search, status filter tabs, sortable table, bulk select with
"Send reminders" and "Mark paid", per-row actions menu, "New invoice" drawer with validation, empty state
and toast feedback.
