Invoices

In the list: J or K or arrow keys move, X selects, R sends a reminder, P marks paid, D duplicates, Delete removes, Enter views.

    Keyboard shortcuts

    J K
    Move down and up the list (arrow keys too)
    X
    Select or unselect the row
    R
    Send reminder (to the selection, or this row)
    P
    Mark paid (the selection, or this row)
    D
    Duplicate as draft
    Delete
    Delete the row
    Enter
    View the invoice
    .
    Open the row's actions menu
    /
    Search
    1-5
    All, Due, Overdue, Paid, Drafts
    N E
    New invoice, Export CSV
    Ctrl K
    Command palette
    Esc
    Close, or clear the selection
