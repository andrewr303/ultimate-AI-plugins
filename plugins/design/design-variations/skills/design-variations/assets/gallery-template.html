Using this gallery

Every frame is a live prototype: click, type and drag inside it. Each one keeps its own state, so nothing you do in one frame changes another.

J / K next or previous option · S shortlist the current option · X mark it "not this" · F open it full size · N add a note · R reset its prototype · Esc close.

Shortlisted options feed "More like my shortlist" and Compare. Options marked "not this" are left out of later rounds unless you ask for them again. Where an option offers a State menu, it switches the prototype between empty, loading, error and other states.
