# Source-reviewed adapter contract draft

Manual research, 2026-10-23. Public source was read, not executed. This draft supports implementation choices; no scanner runtime compatibility test has happened. Exact pinned URLs and local copies appear in `files.json`.

| Tool | Fixed argv proposal (target is one argv element) | Parse | Important boundary |
|---|---|---|---|
| Semgrep | `semgrep scan --json --metrics off --disable-version-check --config <bundled-local-rules.yml> <target>` | `results[]`: `check_id`, `path`, `start.line`, `end.line`, `extra.message`, `extra.severity`, `extra.metadata`; preserve/report `errors[]` | Use local rules to avoid registry downloads; do not use `--config auto` for offline scans. Do not enable autofix. |
| Gitleaks | `gitleaks dir --no-banner --redact=100 --report-format json --report-path - --exit-code 0 <target>` | Root array: `RuleID`, `Description`, `StartLine`, `EndLine`, `File`, `Fingerprint`; ignore `Match`, `Secret`, identity metadata | Full redaction explicitly requested. This is directory content scanning, not git-history scanning. Local `.gitleaks.toml` can change rules and should be reported/controlled. |
| OSV-Scanner v2 | `osv-scanner scan source --format json --recursive <target>` | `results[].source.path`, `results[].packages[].package.{name,version,ecosystem}`, `.vulnerabilities[].{id,summary,details,severity,aliases,affected}`, optional `.groups[]` | Usually needs OSV/deps.dev network; separate opt-in. No packages found is not equivalent to clean; error and absent source coverage stay visible. |
| Bandit | `bandit --recursive --format json --quiet <target>` | `results[]`: `test_id`, `test_name`, `filename`, `line_number`, `issue_text`, `issue_severity`, `issue_confidence`, `issue_cwe.id`; `errors[]` | Exit 1 can mean findings; still inspect errors. Local installed plugins/config can affect execution. Mature optional scanner: code freshness screen failed. |
| Trivy | `trivy filesystem --format json --scanners vuln,misconfig --exit-code 0 <target>` | `Results[].Target`, `.Vulnerabilities[].{VulnerabilityID,PkgName,InstalledVersion,FixedVersion,Severity,Title,Description,PrimaryURL}`, `.Misconfigurations[].{ID,AVDID,Title,Message,Severity,CauseMetadata}` | Vulnerability DB and policies may download; require network opt-in or managed local caches. Omit secret scanner here if Gitleaks covers it; do not expose snippets. |

Read implementation and tests for these five finalists and manifests/licenses. Semgrep source/license is LGPL-2.1 in the observed repository; Gitleaks MIT; OSV-Scanner, Trivy, Bandit Apache-2.0. These are observations of license files, not a claim that every distribution scenario is cleared. Keep scanners as separately installed optional subprocesses; vendor no code/rules from them. Original adapters and bundled original rules avoid copying third-party code. Preserve the uploaded DeepSec Apache notice when deriving the existing engine.

Recent default-branch commits alone can be misleading. Actual code-change detail inspected: Gitleaks latest located code change 2026-02-21 and Bandit 2026-02-23, outside 180 days; select only as explicit mature optional exceptions, do not call them freshly maintained. Semgrep, OSV-Scanner, Trivy, Checkov, ast-grep have verified code changes in the preferred screen. See `candidates.json` for exact SHA and changed files. Trail of Bits skills is ideas-only because its observed source license is CC-BY-SA-4.0.

Tests must distinguish missing scanner, timeout, malformed JSON, scanner errors, no packages/sources and genuinely clean results. Normalize only allowlisted fields; do not include raw subprocess stdout/stderr in user-facing output because scanners can emit secrets. Invoke through `spawn`/`execFile`, never shell command interpolation. Treat repository configuration and scanned files as untrusted data.
