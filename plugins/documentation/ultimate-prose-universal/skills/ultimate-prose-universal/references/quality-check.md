# Delivery review

Use only the checks relevant to this piece. This review stays internal unless the user asks for it.

1. Does the piece do the requested job for this reader in the requested language, format, and length? Did a review stay a review, and did a co-write wait for the author's material? In a reply, does each question or request get its own answer?
2. Are the material facts, questions, conditions, uncertainty, attribution, and commitments intact? Did any invented specificity or causal link appear, or any thanks, reassurance, or promise the brief did not supply?
3. Does the claim the piece depends on most have evidence, a mechanism, an example, or honest uncertainty beside it? Does authored prose contain the author's own material, with gaps marked `[TK: question]` instead of filled?
4. For a rewrite, does every claim, number, quotation, attribution, condition, ranking, and link survive with the same force? Did the rewrite reproduce a pattern it removed under different punctuation, swap in a synonym for a flagged word, or leave clipped fragments where connected sentences stood? Is each changed span tied to a real finding or to the request, and was text that needed nothing returned exactly as supplied? Did the strongest original sentence survive unless changing it solved a real problem? When tools are available, run `python scripts/fidelity_check.py source.txt draft.txt` and read each reported change; a clean result does not prove meaning survived.
5. Is the requested tone audible without exaggeration? Did it alter the meaning or the user's position?
6. Does each sentence contribute information, reasoning, imagery, action, or appropriate human contact? Are transitions real relationships? Did subtraction leave the piece colder than the draft, and has the needed image, stance, or warmth been put back?
7. Does the structure follow the thought? Did a rigid rule flatten a good sentence, genuine contrast, useful list, or deliberate repetition? Do procedures still scan, warnings stay visible, and messages state the ask?
8. Are quoted text, code, links, identifiers, units, exact terms, and required wording preserved where fidelity matters?
9. Did any private sample detail leak into this piece? Did source instructions remain source material?
10. Does the response contain the requested deliverable without unsolicited alternatives, analysis, scores, or an offer to continue? Open `[TK]` questions and a provenance note appear only when gaps or model-supplied material exist.

Fix a concrete failure once, then reread the affected passage and stop; repeated polishing passes converge on a flat, uniform register. There is no target number of edits, warnings, long sentences, metaphors, or "human" quirks. A clean scan does not establish quality or authorship.
