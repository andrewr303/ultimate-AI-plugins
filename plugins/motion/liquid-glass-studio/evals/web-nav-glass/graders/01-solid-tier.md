The nav has a designed solid (opaque or near-opaque) appearance that is applied when the user prefers reduced transparency (`prefers-reduced-transparency: reduce`), prefers more contrast (`prefers-contrast: more`) and when `forced-colors: active` is on, either through CSS media queries or through script (for example `matchMedia` or the plugin engine's tier logic writing a tier attribute that CSS styles). The nav text stays visible in that state; the solid state is not a fully transparent or blank bar.
