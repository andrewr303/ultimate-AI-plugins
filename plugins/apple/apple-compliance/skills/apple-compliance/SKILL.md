# Apple compliance workflow

First read the [operating contract](../../references/operating-contract.md).

## Workflow

1. Resolve actual app/publisher, platform, storefronts, distribution channel, selected artifact/version/build/submission and requested endpoint. Preserve existing user changes and task authority.
2. Read the applicability guide and choose one primary specialist from the router below. Inspect actual product/data/account/purchase/content/extension facts before applying a rule or exception.
3. Build an evidence packet with satisfied, blocked, unknown and not-applicable states. The bundled helper evaluates owner assertions and limited metadata; it does not authenticate facts or remotely check Apple.
4. Implement authorized concrete repairs and meaningful native/product checks. Refresh material policy applicability and current remote identity/state before dependent external actions.
5. Finish with the concrete result, exact evidence and source applicability, furthest observed submission/distribution state and unresolved owner facts. Continue independent work when one dependency is blocked.
