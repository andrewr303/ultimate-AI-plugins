# Compliance discovery and app evidence

First read the [operating contract](../../references/operating-contract.md).

## Workflow

1. Resolve scope and requested stage, then inventory the actual source/dependencies and candidate built artifact without modifying them. Preserve unknown version, account and agreement facts.
2. Map main app, extensions/SDKs, protected resources, network/backend data flows, account lifecycle, purchases, content and representative review tasks with evidence owners.
3. Compare artifact identity/resources with intended app/platform/version/build and selected lane. Treat signing, capabilities, product declarations and remote state as separate checks.
4. Classify each finding as satisfied, blocked, unknown or not applicable with evidence and a reason. Use supported helper profiles only; alternative lanes need manual applicability work.
5. Route the smallest concrete repairs and return a safe inventory, data/feature map, exact observations and pending native/product facts. Static discovery does not certify the app.
