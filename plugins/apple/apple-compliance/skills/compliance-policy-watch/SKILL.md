# Current policy and applicability review

First read the [operating contract](../../references/operating-contract.md).

## Workflow

1. Resolve the concrete rule question and selected platform, storefront, channel, agreement, feature and intended action time. Read the actual source identity and applicable sections after redirects.
2. Record exact URL/title/section, observation date, effective date when known, conditions and evidence owner. Separate Apple policy authority from third-party implementation examples and legal clearance.
3. Compare semantic source/app changes and route only affected work. Preserve future announcements, ambiguous timing and missing eligibility facts as distinct from current readiness.
4. Refresh affected evidence/declarations/artifact tests and current remote state before authorized dependent actions. Keep unknowns visible and complete independent technical repairs.
5. Return source/applicability changes, concrete implementation/test results and remaining owner decisions. Schedule monitoring or send notifications only when explicitly requested.
