# Validation and limits

See [results](validation-results.json) for the actual tests, package/archive checks and native client discovery. Run the commands in [README](../README.md) to reproduce local checks. The portable/native manifest and bibliography validators check structure and contained references, not factual/legal truth, source availability or the correctness of every instruction.

The source/claim records were manually reviewed using the available Research-first Creator workflow because its optional local accelerator projects are absent. No automated research PASS or verified_claims.json is claimed. Narrow cross-author design observations are separated from contextual policy, date, version and rights observations in the research reports.

Native host verification uses isolated task-local state and no model conversation/provider credentials. Apple builds, device behavior, signing, APNs, live databases, App Store actions and legal/product declarations require the actual target environment. Examples and readiness reports retain their stated limits.

Helper portions derive from the existing MIT iOS Development Studio tools and retain that notice. Mutations of malformed metadata, paths, archives and claims are regression-tested. Additional helper/example tests exercise observable behavior; they do not certify an app or production deployment.
