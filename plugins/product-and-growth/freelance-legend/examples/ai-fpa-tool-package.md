# Fictional proposal package

A fictional operations team wants a dashboard that explains forecast changes.
The confirmed sample is a synthetic inventory dashboard built by Morgan Vale.

- **Scope:** Import one sample file, calculate totals in Python, then let the
  assistant explain the largest changes using the calculated values.
- **Acceptance:** Check totals against the supplied fixture. Flag rows with
  missing inputs and leave them out of the explanation.
- **Evidence:** The fictional dashboard is a stand-in for an approved proof item.
  Use only proof cleared in your own local record for a real proposal.
