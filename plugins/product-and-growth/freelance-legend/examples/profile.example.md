# Fictional freelance profile

This sample describes Morgan Vale, a fictional freelancer. To configure the
plugin, put your own profile in the data directory as `profile.md`. Replace
every sample fact before using it for real work.

| Claim | Status |
| --- | --- |
| Builds TypeScript dashboards and Python data imports | Use |
| Can share a synthetic inventory dashboard example | Use |
| Start date, hours, location eligibility and rate | Confirm each time |
| Private account data and unpublished work | Internal |

Record the work you accept, your time zone, pricing preferences, and any proof
you can share. Mark each fact as **Use**, **Confirm**, or **Internal**. Keep
portfolio links and testimonials in your local `approved-proof.md`.
