# Hooks and scripts

Read [script](../../references/script.md) and the campaign brief. Ground factual assertions in the evidence ledger.

1. Define the viewer question and action answering it. Choose one main promise and a result that can be shown clearly.
2. Draft different reasons to care: immediate proof, recognizable problem, before/after or control/trust. Three paraphrases are one hook.
3. Map each spoken/onscreen line to visible action and claim IDs. Preserve input -> action -> result -> benefit -> CTA as appropriate.
4. For short social, start with interest in 1–2 seconds and early proof; these are editable creative targets, not performance claims. Avoid unsupported logo-only openings.
5. Keep the story understandable muted. For narration, use the actual recording/timings to establish durations; never silently accelerate a locked master.
6. Check absolutes, quantities, pricing and security against exact visible evidence. Give result and CTA settled reading time. Derive length from proof and placement constraints.

Deliver script variants with hypotheses, beats and evidence references. Infer ordinary choices and state assumptions; ask only when missing information materially changes production.
