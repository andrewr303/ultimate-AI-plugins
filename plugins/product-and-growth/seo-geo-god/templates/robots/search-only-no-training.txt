#
# SEO-GEO-god robots.txt template, policy mode: search-only-no-training
#
# Purpose: keep classic search crawlers, AI search and answer indexers and
# user-triggered AI fetchers allowed, and state "no training" for AI training
# crawlers and training-control tokens.
#
# REQUIRES OWNER APPROVAL. Publishing this file changes which AI systems may
# crawl and use the site. Review every group with the owner, replace
# example.com, and deploy it as /robots.txt on every host that serves the site.
#
# Facts as of 2026-11-01 (see references/ai-crawlers.md and
# references/current-facts.md in the SEO-GEO-god plugin).
# Re-check on or after: 2026-12-15, 2027-02-01, 2027-03-01, early 2027
# (Google starts honoring the shared training token) and 2027-09-30.
#
# What this file does not do:
# - robots.txt is a preference, not access control. Protect private paths
#   with authentication.
# - Google-Extended does not control Google AI Overviews or AI Mode. Those use
#   Googlebot access, nosnippet, max-snippet, data-nosnippet and the Search
#   Console "Search generative AI" setting.
# - Disallowing Google-Extended also stops grounding in the Gemini app and
#   Vertex AI; it does not affect Google Search.
# - User-triggered fetchers such as ChatGPT-User and Perplexity-User may not
#   follow robots.txt.
# - A CDN or WAF (for example Cloudflare managed robots.txt or bot rules) can
#   change what is served. Check the live response, not only this file.
# - Named groups do not inherit rules from "User-agent: *". Any Disallow line
#   added for private or low-value paths must be repeated in every group.
#
# Optional Cloudflare Content Signals preference (a stated preference, ignored
# by Google). If the owner wants it, add this line inside EVERY group:
# Content-Signal: search=yes, ai-input=yes, ai-train=no

# AI search and answer indexers, and user-triggered fetchers: allowed.
User-agent: OAI-SearchBot
User-agent: ChatGPT-User
User-agent: Claude-SearchBot
User-agent: Claude-User
User-agent: PerplexityBot
User-agent: Perplexity-User
User-agent: Amzn-SearchBot
User-agent: Amzn-User
User-agent: MistralAI-Index
User-agent: MistralAI-User
User-agent: meta-webindexer
User-agent: meta-externalfetcher
User-agent: DuckAssistBot
Allow: /

# AI training crawlers and training-control tokens: disallowed.
# This has no effect on inclusion in Google Search, Bing, ChatGPT search,
# Claude search or Perplexity answers. Bytespider is documented only by third
# parties and its compliance is disputed; use WAF rules if it matters.
User-agent: GPTBot
User-agent: ClaudeBot
User-agent: Google-Extended
User-agent: Applebot-Extended
User-agent: meta-externalagent
User-agent: MistralAI-Training
User-agent: CCBot
User-agent: Bytespider
Disallow: /

# Shared AI-training preference token (IETF individual draft): a preference,
# not a crawler. Bing honors it from 2027-02-01, Google plans early 2027,
# Anthropic is implementing it and OpenAI has announced support.
# "User-agent: *" never matches it, so keep the vendor groups above as well.
User-agent: __usage_ai-training
Disallow: /

# Everyone else, including Googlebot, bingbot and Applebot (Applebot follows
# Googlebot rules when it has no group of its own) and Amazonbot (mixed use;
# Amazon documents the noarchive robots meta tag as a no-training signal).
User-agent: *
Allow: /

Sitemap: https://example.com/sitemap.xml
