# Rule catalog

Generated by `SG rules --format md` from `data/rules.json` (rules version 2026.11.0, as of 2026-11-01). Do not edit this file by hand: change the catalog, then regenerate it. `tests/test_cli.py` checks that the two match.

As of 2026-11-01. Severities, priorities and weights are opinionated defaults. Evidence classes: A official engine or standards documentation, B deterministic spec or structure check, C heuristic (our own thresholds), D experimental (never penalizes a score). Rules with status `planned` are catalogued but never emitted. Scores and priorities are explained in [scoring-and-prioritization.md](scoring-and-prioritization.md).

Priority: P0 fix now (blocks indexing, AI access or rich-result validity site-wide, or ships staging artifacts), P1 this sprint, P2 backlog, P3 optional. Scope `site` means a site-wide rule, which always takes the largest scope multiplier in scores.
