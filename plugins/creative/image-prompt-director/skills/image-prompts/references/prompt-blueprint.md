# Detailed image construction

Use these dimensions as a design checklist, not a form the user must complete. Include only dimensions that affect the requested result. Resolve unspecified choices decisively while keeping user facts fixed.

## A clear hierarchy

1. **Artifact and focal subject.** Name the output: editorial photograph, product hero, watercolor illustration, icon sheet, architectural visualization, poster, cutout, diagram, or another requested form. Name the subject, exact count, defining silhouette and immediate state. State the intended use when it affects composition.
2. **Recognizable structure.** Describe distinguishing geometry, proportions, materials, colors, finish, clothing, pose, expression, gaze, and object interaction. Assign each detail to its actual surface. Keep a product's neck, lid, seams, controls, labels and attachment points coherent.
3. **Space and framing.** Place foreground, subject and background in relation to one another. Specify camera height, view angle, subject size in frame, margins, crop and what remains visible. “Full figure, both feet visible, with ground below the shoes” is more usable than “perfect framing.”
4. **Scene and moment.** Give a definite location, scale, time, environmental state and frozen action. Bound background activity and props so incidental elements do not overwhelm the subject.
5. **Light.** Identify the dominant source, its direction, size/softness, warmth and effect on highlights and shadows. Name any necessary fill or rim source and why it exists. Decide which object casts a visible shadow. Avoid simultaneous instructions that imply opposite exposure or shadow behavior.
6. **Color and material response.** Separate subject colors from surrounding fields. Define useful texture, reflection, translucency, weathering or surface roughness once, where it belongs. Choose restrained contrast and saturation appropriate to the goal.
7. **Style and focus.** Describe the visual medium and mark-making or photographic treatment. Give depth of field, focal plane, motion appearance and grain only when relevant. “Photoreal” alone does not specify the shot. Abstract illustrations do not need a fictitious lens or camera body.
8. **Text and layout.** Quote required text exactly; specify type treatment, line breaks, position, hierarchy, contrast and margins. Separate lettering that must be rendered from copy that will be added later. Preserve numbers, units and punctuation.
9. **Critical constraints.** State hard preservation requirements and a small set of meaningful exclusions. Favor clear visible alternatives over listing everything that could go wrong.

## Detail without noise

Aim for 300–550 words in an initial detailed variant when useful control fills that space. Shorter is right for a tightly scoped edit or an explicitly brief request. Longer is justified for an intricate layout, many necessary relationships or a complex illustration. The goal is enough direction to reduce accidental choices, not a word quota.

Replace empty praise with decisions. “Premium, stunning, award-winning, ultra-high-quality” adds little. Decide whether the bottle is centered or offset, how its label faces the camera, whether its shadow falls to the left, and which edges must remain visible.

Do not stack incompatible styles, arbitrary technical specifications, repeated textures, or many independent lighting schemes. Specify one dominant image strategy. A controlled surreal scene may violate ordinary physics deliberately; name the intended violation and keep the remaining spatial rules understandable.

## Hard locks and creative freedom

Internally divide the brief into:

- **Must remain:** user-provided subject, counts, names, product design, identity, required words, requested medium, view, framing constraints and exclusions.
- **Chosen for this set:** material assumptions needed to make the concept concrete. If the set depends on a character or product design invented from text, establish stable anchors before varying the image.
- **May vary:** remaining composition, light, location, visual rhythm, staging and related artistic choices.

Aesthetic preference is not permission to change facts. If the user asks for a black boot, five colorways fail. If the user requests five colorways, color becomes a controlled variation axis.

## Deliberate variation planning

Build a small mental matrix before writing. Avoid forcing every subject into the same five presets. Possible axes include:

| Axis | Useful controlled changes |
|---|---|
| Framing | Frontal hero, three-quarter, overhead, close detail, environmental wide |
| Spatial design | Centered symmetry, diagonal tension, off-center balance, strong foreground, large copy space |
| Light | Broad window daylight, controlled studio strip, warm sidelight, cool twilight, direct flash |
| Environment | Seamless studio, relevant functional context, tactile set, restrained natural location, minimal architectural space |
| Narrative | Quiet anticipation, visible use, aftermath, discovery, deliberate display |
| Graphic treatment | Typographic hierarchy, pattern rhythm, color field, cut-paper layering, information-led layout |

Choose two or three axes per alternative; keep the set coherent enough for comparison. Explain each variation's difference in one line outside its block. If the user wants a controlled A/B test, vary only the nominated axis rather than broad creative direction.

## Standalone copy blocks

Include all needed context in each block: artifact, subject and hard locks, complete visual direction, text, reference roles, and preservation instructions. A settings note outside the block can describe actual UI controls, but must not be the only place where a critical creative requirement appears.

Media assignments are external dependencies. A block may say “Reference A is the subject identity, Reference B controls clothing, and Reference C is background style only”; the output must also tell the user to attach those exact files and in what order when the target interface requires it. A textual label does not attach a file or guarantee that the model accepts it.

If no image is attached, do not write “match the attached portrait” as if one exists. Either create the design from the user's text, or clearly mark the missing input and write a provisional preservation-based prompt.
